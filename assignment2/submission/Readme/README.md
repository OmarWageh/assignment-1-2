# Calculator

## Project Description

This is a simple console-based Calculator application developed in C#.

The application takes two numbers from the user and performs the following arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division

The calculator also handles division by zero and allows the user to perform calculations repeatedly without restarting the application.

## Language and Technologies

- C#
- .NET
- Console Application

## Features

- Take two numbers from the user.
- Perform addition.
- Perform subtraction.
- Perform multiplication.
- Perform division.
- Handle division by zero.
- Allow multiple calculations during the same application run.
- Display the results clearly.



### Requirements

- .NET SDK installed on your computer.
- Visual Studio, Visual Studio Code, or another C# development environment.
